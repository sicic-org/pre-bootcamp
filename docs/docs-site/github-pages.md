# GitHub Pages: Going Public

This is the final step of your Intro-Track journey: Hosting your personal wiki for the world (and potential Patrons) to see.

### The Automated Pipeline
1. **The Repository**: Create a repo named `yourname-knowledge-base`.
2. **The Action**: We use **GitHub Actions**. Every time you `git push` new notes from your VPS, GitHub will automatically:
    - Build your MkDocs site.
    - Deploy it to `https://yourname.github.io/`.

### The Result
You now have a live URL that serves as your **Proof of Build**. It proves you can not only build an AI system but also document and transmit the knowledge.
